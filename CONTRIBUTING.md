# Contributing to VISION Green Mobility Hub

Thank you for your interest in Northern Ethiopia's first Open Source Mobility OS.

## 1. Code of Conduct
This project is a **Fiduciary Instrument** for veteran reintegration.
- No discriminatory language.
- Accessibility (a11y) is mandatory for our PWD technicians.

## 2. Technical Standards
- **Language:** All code comments must be in English.
- **Offline First:** All features must work on 3G networks in Tigray.

## 3. Security
Do not commit real passwords or TeleBirr API keys. Use environment variables.
